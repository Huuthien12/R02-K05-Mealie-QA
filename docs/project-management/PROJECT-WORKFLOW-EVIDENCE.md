# Project Workflow Evidence

Repository history chứng minh workflow branch-per-phase, commit/push và PR merge vào `main` (ví dụ merge PR #4 P1, #5 defect RCA, #6 reproducibility, #7 final report). `main` là baseline tích hợp; branch feature giữ thay đổi trước review/merge. Defect log là living record và evidence không bị rewrite.

Role allocation được ghi trong `README.md` và được tóm tắt ở `reports/final/TEAM-CONTRIBUTIONS.md`. Git branches/commits/PRs cung cấp work history ở mức repository, **không tự chứng minh đóng góp cá nhân bằng nhau**.

**Chưa có bằng chứng trong repository cho việc sử dụng Trello/Jira/GitHub Projects.** Không được suy diễn hoặc tạo board giả. Các artefact thực tế của workflow là Git history, PR merge, test summaries, defect log và evidence preservation.
